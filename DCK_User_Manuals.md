# USER MANUAL 1: SCHOOL ADMIN (Head Teacher / Principal)
# *(Print and give to: School Admin)*

## How to Login
1. Open your browser (Chrome recommended)
2. Go to the school system URL (given by DCK Solutions)
3. Enter your **email** and **password**
4. Click **Login**
5. You will see your **Dashboard**

## Your Dashboard
When you login, you see:
- **Employee Count** - total staff in your school
- **Student Count** - total enrolled students
- **Parent Count** - total registered parents
- **Teacher Count** - total teachers
- **Monthly Income vs Expense** chart
- **Annual Fee Summary** - total fees, paid, and due
- **Student Distribution** by class (pie chart)
- **Attendance Overview** for the current week
- **Subscription Status** - days remaining on your plan
- **Calendar** - showing school events

## Your Menu (What You Can Do)

### ADMISSION (Adding New Students)

**Create Admission** (add one student):
1. Click **Admission > Create Admission**
2. Select Academic Year, Class, Stream
3. Register No is auto-generated (you can change it)
4. Enter Roll Number (next number in the class)
5. Fill: First Name, Last Name, Gender, Date of Birth, Phone, Email
6. Enter UPI Number (NEMIS) if available
7. Set a password (student will use this to login)
8. Fill Guardian details OR select existing guardian
9. Click **Save**
10. Student is now enrolled and can login

**Multiple Import** (add many students from CSV):
1. Click **Admission > Multiple Import**
2. Click **Download Sample Import File**
3. Open the CSV in Excel, fill student details row by row
4. Save as CSV
5. Select Class and Stream
6. Upload the file, click **Import**

**Admission Requests** (approve teacher requests):
1. Click **Admission > Admission Requests**
2. You see pending requests with yellow badge
3. Click the **eye icon** to view student details
4. Click **Approve** (green) to enroll the student
5. Click **Reject** (red) with a reason to decline

**Student Categories:**
1. Click **Admission > Category**
2. Add categories: Regular, Scholarship, Bursary, Special Needs

### STUDENT DETAILS

**View Student List:**
1. Click **Student Details > Student List**
2. Select Class and Stream, click **Search**
3. You see all students with photo, name, roll, register number
4. Click a student's name to view their full profile

**Student Profile:**
- View/edit personal details
- View fee payment history
- View exam results
- Upload student documents
- Change student password
- Deactivate student account

**Generate ID Cards:**
1. Click **Student Details > ID Card**
2. Select Class and Stream
3. Check students you want
4. Click **Generate** - printable ID cards with QR code appear

### PARENTS

**View Parents:**
1. Click **Parents > Parent List**
2. See all registered parents with their children
3. Click to view/edit parent details

### EMPLOYEE MANAGEMENT

**Add Employee:**
1. Click **Employee > Add Employee**
2. Fill: Name, Department, Designation, Qualification
3. Select **System Role**: Teacher, Accountant, or Librarian
4. Enter their email (this is their login)
5. Set a password
6. Click **Save**

**Departments:** Click **Employee > Department** to add/edit departments

**Designations:** Click **Employee > Designation** to add/edit job titles

### ACADEMICS

**Classes:**
1. Click **Academics > Classes**
2. To add: Enter name, numeric value, select Curriculum Type (CBC or 8-4-4), Level, and Streams
3. Click **Save**
4. The list shows all classes with their curriculum type badge

**Sections:** Click **Academics > Sections** to add streams (A, B, C)

**Subjects:**
1. Click **Academics > Subjects**
2. Add: Name, Code, Type (Theory/Practical)
3. Click **Save**

**Subject Class Assignment:** Link subjects to classes

**Subject Teacher Assignment:** Assign which teacher teaches which subject in which class

**Assign Class Teacher:** Assign one class teacher per class/stream

**Class Timetable:**
1. Click **Academics > Class Timetable**
2. Select Class and Stream
3. For each day, add: Start time, End time, Subject, Teacher, Room
4. Check **Break** for tea/lunch breaks
5. Click **Save**

**Student Promotion:**
1. Click **Academics > Student Promotion**
2. Select current Class and Stream
3. Click **Search** - see all students
4. Set: Promote to Session (new year), Promote to Class (next class), Promote to Section
5. Check students who passed, uncheck repeaters
6. Assign new roll numbers
7. Click **Save**

### CBC ASSESSMENT (for PP1 to Grade 9)

**Learning Areas:**
1. Click **CBC Assessment > Learning Areas**
2. Add learning areas per level (Lower Primary, Upper Primary, Junior Secondary)
3. The Kenya template already creates these for you

**Strands:**
1. Click **CBC Assessment > Strands**
2. Add sub-topics within each learning area

**Assessment Entry:**
1. Click **CBC Assessment > Assessment Entry**
2. Select Class, Stream, CBC Exam, Learning Area
3. Click **Search**
4. For each student, select: **EE**, **ME**, **AE**, or **BE**
5. Add optional remarks
6. Click **Save Assessment**

**Behaviour Assessment:**
1. Click **CBC Assessment > Behaviour Assessment**
2. Select Class, Stream, Exam
3. Rate each student on: Social, Spiritual, Emotional, Physical, Creative
4. Click **Save**

**CBC Report Card:**
1. Click **CBC Assessment > CBC Report Card**
2. Select Session, Exam, Class, Stream
3. Check students you want
4. Set print date
5. Click **Print Report Card**

### EXAM MASTER (for Form 1-4)

**Exam Terms:** Already created (Term 1, 2, 3)

**Mark Distribution:** Already created (CAT 1, CAT 2, End Term)

**Exam Setup:**
1. Click **Exam Master > Exam**
2. Click **Add** button
3. Enter: Exam Name (e.g. "Form 1 Term 2 Exam 2026")
4. Select: Term, Grading System (Traditional or CBC), Mark Distributions
5. Click **Save**

**Exam Halls:** Already created (Hall A, B, C)

**Exam Schedule:**
1. Click **Exam Schedule**
2. Select Exam, Class, Stream
3. For each subject: Set date, time, hall, full marks, pass marks
4. Click **Save**

**Mark Entry:**
1. Click **Marks > Mark Entries**
2. Select Exam, Class, Stream, Subject
3. Click **Search**
4. Enter marks for each student (CAT 1, CAT 2, End Term)
5. Check **Absent** if student didn't sit the exam
6. Click **Save**

**Grades Range:** Already created (KCSE grading A to E)

**Report Card:**
1. Click **Exam Reports > Report Card**
2. Select Session, Exam, Class, Stream
3. Check students, click **Print**

**Tabulation Sheet:**
1. Click **Exam Reports > Tabulation Sheet**
2. Select Session, Exam, Class, Stream
3. Click **Filter** - see all students' marks side by side

### STUDENT ACCOUNTING (Fees)

**Fees Type:** Already created (Tuition, Activity, Lunch, etc.)

**Fees Group:**
1. Click **Student Accounting > Fees Group**
2. Create: "Term 2 Fees - Primary"
3. Check fee types and set amounts + due dates
4. Click **Save**

**Fees Allocation:**
1. Click **Student Accounting > Fees Allocation**
2. Select Class, Stream, Fee Group
3. Click **Search**
4. Check students to assign fees to
5. Click **Save**

**Collect Fees (Payments History):**
1. Click **Student Accounting > Payments History**
2. Select Class and Stream, click **Filter**
3. Click **Collect** next to a student
4. Click the **Collect Fees** tab (3rd tab)
5. Select fee type, enter amount, select payment method (Cash/M-Pesa/Cheque)
6. Click **Fee Payment**

**Due Fees Invoice:** See all students with unpaid balances

**Fees Reminder:** Set up automatic SMS reminders

### ATTENDANCE

**Student Attendance:**
1. Click **Attendance > Student Attendance**
2. Select Class, Stream, Date
3. Mark each student: **P** (Present), **A** (Absent), **L** (Late)
4. Click **Save**

**Employee Attendance:** Same process for staff

### HOMEWORK

1. Click **Homework**
2. Click **Add**
3. Select Class, Stream, Subject
4. Write description, set due date
5. Click **Save**
6. After due date: Click **Evaluation** to grade students

### COMMUNICATION

**Send SMS/Email:**
1. Click **Communication > Send SMS/Email**
2. Select recipients (all parents, specific class, or individual)
3. Write message
4. Click **Send**

### HRM (Payroll & Leave)

**Salary Payment:**
1. Click **HRM > Payroll > Salary Payment**
2. Select Role, Month, Year
3. Click **Search**
4. Click **Generate** next to a staff member
5. Review salary breakdown, click **Paid**

**Leave Management:**
1. Click **HRM > Leave > Manage Applications**
2. See pending leave requests
3. Click **Approve** or **Reject**

### OFFICE ACCOUNTING

**New Deposit:** Record income (fees, grants, donations)
**New Expense:** Record expenses (bills, supplies)
**All Transactions:** View complete financial ledger

### SCHOOL SETTINGS

**Email Config:** Set up Gmail SMTP for notifications
**SMS Config:** Set up Africa's Talking for SMS
**Payment Gateway:** Configure M-Pesa credentials

# USER MANUAL 2: TEACHER
# *(Print and give to: Each Teacher)*

## How to Login
1. Open browser, go to the school system URL
2. Enter your **email** and **password** (given by admin)
3. Click **Login**

## Your Dashboard
You see your assigned classes and upcoming school events.

## What You Can Do

### TAKING ATTENDANCE (Do this every morning)
1. Click **Attendance** in the menu
2. Select your **Class** and **Stream**
3. Select **today's date**
4. For each student, click:
   - **P** = Present (green)
   - **A** = Absent (red)
   - **L** = Late (yellow)
5. Add a remark for absent students (e.g. "Sick", "No reason given")
6. Click **Save**
7. Done! Takes about 2 minutes

### REQUESTING STUDENT ADMISSION

**Single Student:**
1. Click **Admission > Request Admission**
2. Fill the student's details (name, DOB, class, parent info)
3. Click **Submit Admission Request**
4. The school admin will review and approve it
5. Track your requests at **Admission > Admission Requests**

**Bulk Import (many students at once):**
1. Click **Admission > Bulk Request (CSV)**
2. Click **Download Sample CSV File**
3. Open in Excel, fill student details
4. Select Class and Stream
5. Upload the file, click **Submit**
6. All students go to admin for approval

### ASSIGNING HOMEWORK
1. Click **Homework** in the menu
2. Click **Add**
3. Select your **Class**, **Stream**, and **Subject**
4. Write the homework description clearly
5. Set the **homework date** (today) and **submission deadline**
6. You can attach a file (PDF, image)
7. Click **Save**
8. Students and parents will see this in their portal

**Grading Homework:**
1. Click **Homework** in the menu
2. Find the homework you assigned
3. Click **Evaluation**
4. For each student: enter a mark/rank and write remarks
5. Click **Save**

### ENTERING EXAM MARKS (Form 1-4)
1. Click **Marks > Mark Entries**
2. Select: **Exam**, **Class**, **Stream**, **Subject**
3. Click **Search**
4. You see all students listed
5. Enter marks for each column:
   - **CAT 1** (out of 30)
   - **CAT 2** (out of 30)
   - **End Term** (out of 70)
6. If a student was absent, check the **Absent** box
7. Click **Save**
8. The system calculates grades and totals automatically

### ENTERING CBC ASSESSMENTS (PP1 to Grade 9)
1. Click **CBC Assessment > Assessment Entry**
2. Select: **Class**, **Stream**, **CBC Exam**, **Learning Area**
3. Click **Search**
4. For each student, select the competency level:
   - **EE** = Exceeding Expectations (student is excellent)
   - **ME** = Meeting Expectations (student is doing well)
   - **AE** = Approaching Expectations (student needs help)
   - **BE** = Below Expectations (student is struggling)
5. Write optional remarks for each student
6. Click **Save Assessment**
7. Repeat for each learning area

**Behaviour Assessment:**
1. Click **CBC Assessment > Behaviour Assessment**
2. Select Class, Stream, Exam
3. Rate each student on 5 areas:
   - **Social** - How they interact with others
   - **Spiritual** - Moral values and respect
   - **Emotional** - Self-control and maturity
   - **Physical** - Sports and physical fitness
   - **Creative** - Art, music, creativity
4. Use EE/ME/AE/BE for each
5. Click **Save**

### VIEWING TIMETABLE
Click **Academics > Class Timetable** to see your teaching schedule for the week.

### APPLYING FOR LEAVE
1. Click **HRM > Leave > My Application**
2. Click **Add**
3. Select leave type: Annual, Sick, Compassionate, etc.
4. Enter start date and end date
5. Write the reason
6. Attach a document if needed (e.g. doctor's note)
7. Click **Submit**
8. The admin will approve or reject your request
9. Check status anytime on this same page

### LIBRARY
Click **Library > Books** to browse the school library and request books.

### MESSAGES
Click **Message > Mailbox** to send/receive messages with other staff or parents.

# USER MANUAL 3: ACCOUNTANT / BURSAR
# *(Print and give to: Accountant)*

## How to Login
1. Open browser, go to the school system URL
2. Enter your **email** and **password**
3. Click **Login**

## Your Main Job: Collecting Fees

### STEP 1: See Who Needs to Pay
1. Click **Student Accounting > Payments History**
2. Select **Class** and **Stream**
3. Click **Filter**
4. You see all students with their status:
   - 🔴 **Unpaid** - has not paid anything
   - 🔵 **Partly Paid** - has paid some
   - 🟢 **Fully Paid** - has paid everything

### STEP 2: Collect Payment
1. Click **Collect** next to the student's name
2. You see 3 tabs at the top:
   - **Invoice** - shows what they owe
   - **Payment History** - shows what they've paid before
   - **Collect Fees** - where you enter the payment
3. Click the **Collect Fees** tab
4. Fill in:
   - **Fees Type**: Select which fee (Tuition, Lunch, etc.)
   - **Date**: The date of payment
   - **Amount**: How much they are paying (can be partial)
   - **Discount**: Enter if any discount applies
   - **Payment Method**: Cash, M-Pesa, Cheque, Bank Transfer
   - **Remarks**: Write the M-Pesa code or cheque number
5. Click **Fee Payment**
6. The payment is recorded. Balance updates automatically.

**Example - Parent pays KES 10,000 cash for tuition:**
- Fees Type: Tuition Fee
- Amount: 10000
- Payment Method: Cash
- Remarks: Cash payment

**Example - Parent pays via M-Pesa:**
- Fees Type: Tuition Fee
- Amount: 15000
- Payment Method: M-Pesa
- Remarks: M-Pesa QKL2XY789

### STEP 3: Check Outstanding Fees
Click **Student Accounting > Due Fees Invoice** to see ALL students with unpaid balances across all classes.

### STEP 4: Send Fee Reminders
1. Click **Student Accounting > Fees Reminder**
2. Set: Frequency (before/after due date), Days, Message
3. The system sends SMS automatically to parents with unpaid fees

### Setting Up Fees (usually done once per term)

**Fee Types** (Student Accounting > Fees Type):
Already created: Tuition, Activity, Lunch, Exam, Development, Transport, Boarding, Stationery, Medical, Library

**Fee Groups** (Student Accounting > Fees Group):
1. Click **Add**
2. Name: "Term 2 Fees - Primary"
3. Check the fee types that apply
4. Enter amount and due date for each
5. Click **Save**

**Fee Allocation** (Student Accounting > Fees Allocation):
1. Select Class, Stream, Fee Group
2. Click **Search**
3. Check all students who should pay this fee group
4. Click **Save**

### Office Accounting

**Recording Income:**
1. Click **Office Accounting > New Deposit**
2. Select Account, Category (e.g. "Government Grants")
3. Enter amount, date, description
4. Click **Save**

**Recording Expenses:**
1. Click **Office Accounting > New Expense**
2. Select Account, Category (e.g. "Electricity Bill")
3. Enter amount, date, description (e.g. "Kenya Power June 2026")
4. Click **Save**

**Viewing Transactions:**
Click **Office Accounting > All Transactions** for the complete financial ledger.

### Payroll (Monthly Salary Processing)

1. Click **HRM > Payroll > Salary Payment**
2. Select Staff Role, Month, Year
3. Click **Search**
4. For each staff member, click **Generate**
5. Review the breakdown: Basic + Allowances - NHIF - NSSF - PAYE = Net
6. Select payment method
7. Click **Paid**
8. Payslip is generated and can be printed

### Reports You Can Generate

| Menu | What it shows |
|------|-------------|
| Fees Report > Student Fees Report | Each student's payment details |
| Fees Report > Due Fees Report | All unpaid balances |
| Fees Report > Fine Report | Late payment penalties |
| Accounting > Income vs Expense | Monthly comparison |
| Accounting > Account Statement | Bank account history |
| HRM > Payroll > Summary | Monthly salary totals |

# USER MANUAL 4: LIBRARIAN

## How to Login
1. Open browser, go to the school system URL

## What You Can Do

### ADDING BOOKS
1. Click **Library > Books**
2. Click **Add**
3. Fill: Title, Author, ISBN, Category, Publisher, Edition
4. Enter purchase date, price, total copies
5. Click **Save**

### BOOK CATEGORIES
1. Click **Library > Categories**
2. Categories already created: Textbooks, Fiction, Reference, Kiswahili Literature, etc.

1. Click **Library > Manage Books**

Students can request books from their portal.
1. Click **Library > Book Requests**
2. See pending requests
3. Click **Accept** to issue the book
4. Click **Reject** if the book is not available

### CHECKING BOOK STATUS
- Click **Library > Books** to see total stock vs issued copies
- Books with 0 available copies cannot be issued until returned

# USER MANUAL 7: SUPERADMIN (DCK Solutions)
# *(For DCK Solutions internal use only)*

## Your Role
You manage the entire platform - all schools, subscriptions, and system settings.

## Login
Use your superadmin email and password.

## Key Tasks

### Creating a New School
1. Click **Branch > Manage Branches**
2. Fill: Branch Name, School Name, Email, Phone, Currency (KES), City, County, Address
3. The **Kenya Template** checkbox is checked by default
4. Click **Save**
5. The system auto-creates: 15 classes, 3 streams, all subjects, learning areas, grading scale, fee types, salary templates, and more

### Managing Subscriptions
1. Click **Branch > Subscriptions** to see all schools
2. Each school shows: Plan, Days Left, Status
3. **Activate** - Click green button when school pays
4. **Deactivate** - Click red button to cut off access
5. **Extend** - Click calendar button to add days (30/60/90/180/365)

### Payment Settings
1. Click **Branch > Subscriptions > Payment Settings**
2. Enter your M-Pesa Paybill number
3. Schools see this Paybill when their subscription is expiring

### Setting Permissions
1. Click **Settings > Role & Permission**
2. Click **Manage** next to a role (e.g. Teacher)
3. Check/uncheck View, Add, Edit, Delete for each feature
4. Click **Update**

### Creating Academic Sessions
1. Click **Settings > Session Settings**
2. Add new year (e.g. "2027")
3. Update active session in Global Settings

### System Settings
- **Settings > Global Settings** - System name, logo, timezone
- **Settings > Translations** - Change language
- **Settings > Backup** - Download database backup (do weekly)

### Monitoring Schools
- Click on any branch name in the Dashboard to see that school's stats
- Check fee collection, attendance, student counts per school

### When a School Calls After Paying
1. Ask for their **M-Pesa confirmation code** and **school name**
2. Go to **Branch > Subscriptions**
3. Find the school
4. Click **Extend** and select 30 days (or however long they paid for)
5. School is immediately active again
